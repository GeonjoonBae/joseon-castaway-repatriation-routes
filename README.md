# Joseon Castaway Repatriation Routes

Anonymous pre-publication companion maps prepared for peer review.

The site contains only the layers rendered in Figures 2, 3, and 4 of the associated article draft. Route lines and station locations are scholarly reconstructions and should not be interpreted as exact travelled alignments or surveyed station sites.

## Figures

- Figure 2 compares two reconstructed repatriation routes and their shared official-network section.
- Figure 3 compares the Guangzhou-Beijing postal baseline, a waterway detour, and two Shandong alternatives.
- Figure 4 presents the Grand Canal section of the Fujian corridor and three reconstructed water-land transition points.

## Use

Open `index.html` through a web server. The deployed GitHub Pages site requires no server-side application.

```powershell
python -m http.server 8765
```

Then open `http://127.0.0.1:8765/`.
